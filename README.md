# Media Social CrewAI 🤖📱

Multi-agent AI system designed for automated social media management. It helps grow your audience and generate leads on LinkedIn and Facebook by creating high-quality, targeted content.

## 🌟 Key Features
- **Multi-Agent Orchestration**: Built with CrewAI to handle research, writing, and formatting.
- **Content Optimization**: Tailored post creation for LinkedIn (professional) and Facebook (engaging).
- **Automated Workflow**: Generates ready-to-publish content from simple topic inputs.

## 🛠️ Tech Stack
- **Language**: Python 3.10+
- **Framework**: CrewAI
- **LLM**: Google Gemini API

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have Python installed and your Gemini API key ready.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone [https://github.com/Freddy-devops/Media_social_crewai.git](https://github.com/Freddy-devops/Media_social_crewai.git)
cd Media_social_crewai
pip install crewai langchain-google-genai
